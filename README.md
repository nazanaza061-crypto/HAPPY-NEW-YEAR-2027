# Happy New Year 2027 — Luxe Edition

เวอร์ชันปรับภาพลักษณ์ให้หรูหราขึ้น โดยคงลำดับแอนิเมชันเดิมไว้:
- หน้า Welcome พร้อมปุ่ม PRESS ENTER
- กด Enter แล้วซูมออกเข้าสู่ฉากเมืองกลางคืน
- พลุเริ่มแสดงบนท้องฟ้า
- ข้อความ HAPPY NEW YEAR 2027 อยู่กลางภาพ
- Grand Finale พลุหลายจุดพร้อมกัน

## เปิดดูในเครื่อง
เปิด `index.html` ด้วย Chrome หรือ Edge

## Deploy บน Render
1. อัปโหลดไฟล์ทั้ง 4 ไฟล์ในโฟลเดอร์นี้ไปยัง GitHub repository
2. ใน Render เลือก **New + → Static Site**
3. เชื่อมต่อ GitHub repository
4. Build Command เว้นว่าง
5. Publish Directory ใส่ `.`
6. กด **Create Static Site**

หมายเหตุ: ฟอนต์ Montserrat และ Cormorant Garamond โหลดจาก Google Fonts เมื่อมีอินเทอร์เน็ต หากออฟไลน์จะใช้ฟอนต์สำรองแทน
