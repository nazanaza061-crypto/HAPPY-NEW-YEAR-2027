# Happy New Year 2027

A static browser animation with:
- Welcome screen and PRESS ENTER
- Zoom-out transition into a night city scene
- Fireworks and centered HAPPY NEW YEAR 2027 message
- Grand finale fireworks

## Run locally
Open `index.html` in a modern browser.

## Deploy on Render
1. Push this folder to a GitHub repository.
2. In Render, choose **New + → Static Site**.
3. Connect the GitHub repository.
4. Set **Build Command** to blank.
5. Set **Publish Directory** to `.` (a single dot).
6. Click **Create Static Site**.

No Python server or build step is needed.
